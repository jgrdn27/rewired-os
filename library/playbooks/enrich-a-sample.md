# Enrich a useful sample

Use when a selected list lacks information needed for a defined decision or action. Original Rewired method; no credit use is implied by reading it.

1. Identify the decision the missing fields support. Inspect the file schema and a bounded sample, not the entire dataset in chat. Preserve the original; identify duplicates and existing verified values.
2. Build the smallest field map. Specify identifiers, required outputs, freshness needs, and when a blank is preferable to an uncertain match. Exclude records outside the intended scope.
3. Read the selected enrichment tool profile and execution contract. Check current unit costs and account balance. Prepare sample size, maximum volume/credits, output destination, and retry policy within the user's authorization.
4. Execute only the authorized sample. Retain provider job IDs and check completion before any retry. Join results back using stable keys; do not overwrite verified fields with weaker matches.
5. Evaluate match accuracy as well as fill rate. Report records attempted, useful verified additions, unresolved records, actual cost when known, and whether expansion is justified. A high fill rate alone does not prove good targeting.

Deliverable: a separate enriched sample with source/date/status fields, a cost and quality note, and a next-step recommendation. Export to a sequencer or CRM only under the separate requested scope. A bulk expansion needs existing authorization that covers its actual volume and cost.
