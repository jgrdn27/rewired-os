# Carry a process through

Read `work/index.md` and `docs/playbooks.md` from the Rewired root. Find the relevant project and the selected method. Use the existing task system when it owns progress. An ordinary draft does not need a run record.

For a new run, reuse the project's outcome, evidence, and authorization. Ask only for missing choices that affect execution. Use `templates/playbook-run.md` in a new run folder within the project, with a descriptive name that distinguishes it from earlier runs. Keep user methods under `work/` or in their existing location; never personalize a stock template. Record the selected checkpoints and completion criteria so later edits to the method do not silently change this run. Link the run from the project brief without duplicating its progress.

For an existing run, read its record and the evidence for the next action. Establish which results are verified, which are merely drafts or reports, and whether any supporting artifact has changed. Keep consequential corrections visible. A missing artifact, uncertain external status, or changed approved version requires reconciliation before relying on that checkpoint.

Do the next authorized work and check its actual result. Save the deliverable first, then update the run with its exact version or path, evidence date, checkpoint state, and continuation. Record an external attempt separately from confirmation of its outcome. Recover an interrupted attempt by checking its result before retrying. Do not repeat completed work just because this is a fresh conversation.

Continue through useful internal steps within the request. Stop at a material missing choice, unavailable capability, or action outside the user's authorization. A review request is satisfied by a reviewable artifact; it does not authorize publication. A date or waiting condition records when work can proceed, not a scheduled job.

Read back the saved continuation and check its links. Report the latest result, any unresolved condition, and the next action. With read-only access, return an unsaved update or an authorized handoff. Do not claim the run advanced on disk.
