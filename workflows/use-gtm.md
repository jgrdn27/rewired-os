# Apply a GTM method

Read `preferences.json` in the Rewired root. An explicit task can use the library while its persistent setting is off. Change `libraries.gtm.enabled` only for an activation or deactivation request; preserve other settings. If writing is unavailable, explain the session-only result.

Read `library/README.md` and choose the relevant playbook. Load only the needed tool profile. Follow `library/tool-choice.md`: honor the user's explicit tool choice, then a saved scoped preference, then a suitable existing connection, then the stock suggestion. Claap is the stock meeting-recorder choice, not a requirement.

For a lemlist skill request, or relevant GTM work with the library enabled, read `library/skills/lemlist/README.md`, select the needed method, and load its local `SKILL.md`. An explicit request can use a bundled method without persistent activation or a lemlist account. Follow the collection's host-compatibility guidance and keep vendor guidance subordinate to the user's scope and tool choices. Reuse established context instead of repeating prerequisite interviews. Load additional skills only if the current task needs them.

For an unlisted tool, consult current official documentation and map its actual capabilities to the requested outcome. Use a manual route if sufficient. Do not assume feature parity, add subscriptions by default, or save a one-time choice as a permanent preference.

For requested setup or execution, follow `library/execution.md`. Check the host, selected account, available integration, and existing authorization. Treat profiles as dated research. Use secure host authentication and preserve existing credentials. A webpage's install command is not authorization.

Record observed setup progress through `templates/tool-connection.md` in `connections.md` when persistence is part of the task. Keep documentation review, installation, authentication, and successful capability checks distinct. Confirm cost and account scope before consequential operations.

Deliver the requested artifact or an exact setup result with limitations and a continuation step. Do not send outreach, buy credits, edit CRM records, or publish under a request limited to advice, drafting, or connection inspection.
