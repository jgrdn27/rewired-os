# Choose the work, not a command

These visible files make Rewired's methods accessible to file-capable assistants without a skill installer. Each workflow is generated from its canonical `.agents/skills` source; edit the source and run `scripts/sync_skills.py` when developing the stock package.

| User need | Read only this workflow |
|---|---|
| Personalize or refresh your OS | [Get started](first-win.md) |
| Bring research or a handoff into the wiki | [Bring in](bring-in.md) |
| Start or organize a project | [Start a project](start-project.md) |
| Continue unfinished work | [Pick up](pick-up.md) |
| Explore a decision | [Think it through](think-it-through.md) |
| Improve how work gets done | [Work review](work-review.md) |
| Polish a selected draft | [Polish a draft](polish-draft.md) |
| Check system behavior | [System check](system-check.md) |
| Activate GTM methods or use a listed tool | [Use GTM](use-gtm.md) |

Reading instructions does not provide tool execution. Follow the capability limits in [portability](../docs/portability.md).
