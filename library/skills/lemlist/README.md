## Use with Rewired OS

Load only the selected skill and any prerequisite genuinely missing from the user's context. Existing confirmed ICP, persona, and offer records can satisfy prerequisite questions. A one-time request does not change `libraries.gtm.enabled`; with the library enabled, select these methods when relevant to GTM work. Personal tasks stay on their own routes.

Apply the user's instructions and Rewired's [execution contract](../../execution.md) and [tool-choice policy](../../tool-choice.md) when using vendor guidance. Respect the user's selected tools, existing authorization, and current host capabilities. A vendor recommendation or sample labeled AUTO_MERGE is not permission to mutate a CRM or contact someone. Drafting, analysis, and workflow JSON do not launch campaigns or activate workflows.

The originals contain Claude-specific assumptions. Adapt output paths such as `/mnt/user-data/outputs` and `/home/claude` to an available user-owned destination. Use the host's supported browser, artifact, file, and integration tools instead of assuming `web_fetch`, a Claap MCP, a particular deck renderer, or global dependencies exist. Use the host's maintained presentation workflow for producing decks. Inspect actual dependencies before installing anything; example commands using `--break-system-packages` are not required setup steps. If execution is unavailable, return a useful draft or clearly describe the missing capability.

Vendor benchmarks, product features, and API examples are dated source claims. Attribute benchmarks to lemlist and verify current official documentation before relying on live interfaces or making current product claims. The Claap opportunity detector was written for Claap's sales team: use it for that product only when requested, or adapt its criteria to the user's actual offer before analysis.
