# Think it through

These are project workflows. Resolve paths from the OS workspace root containing `AGENTS.md` and `START-HERE.md`; do not install this skill alone.

Start with the desired outcome: a decision, a short brief, or an explicitly labeled set of open questions. Read relevant existing context before asking. Offer a short exploration first; a deeper interview is optional.

Ask one useful question at a time, resolving dependencies. When the user has requested a saved exploration, create a uniquely named dated capture under `work/discovery/` and checkpoint each answer before proceeding. Distinguish confirmed facts from suggestions and uncertainty. If saving fails, preserve the answer in chat and resolve storage before collecting more.

Stop when the requested outcome is reached, a material unknown needs another owner, or the user pauses. Avoid an endless interrogation. Give a concise synthesis with alternatives, tradeoffs, and unresolved assumptions. A recommendation is not a user decision.

Only update canonical context when context-building was requested and the fact is user-confirmed. Save confirmed decisions when asked. Route a useful saved capture from `work/index.md`; do not create a root-manual entry for every conversation. Never send messages or change external systems as part of the interview.
