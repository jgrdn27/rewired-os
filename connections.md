# Source access

No external connection is configured. Add only sources relevant to actual work.

For each route record: purpose, account/activity scope, exact entry point, access method, read/write boundary, latest successful useful read, freshness expectation, and known limitations. A tool name or installed plugin is not evidence of account access. Store credential instructions, never credential values.

Use the [access-record template](templates/access-record.md) for local/cloud file routes and the [tool-connection template](templates/tool-connection.md) for GTM tools. Verify canonical file identity across routes rather than assuming matching filenames represent the same file.
