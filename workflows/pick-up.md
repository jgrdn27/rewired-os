# Pick up

These are project workflows. Resolve paths from the OS workspace root containing `AGENTS.md` and `START-HERE.md`; do not install this skill alone.

Read `work/index.md`, then the selected project brief or external authoritative record and the needed supporting sources. Use `docs/projects.md` for the brief contract when relevant. Do not require migration of older work entries just to resume them. Resolve the latest deliverable and authoritative status, keeping event dates distinct from export dates. Search narrowly if the route is missing and report the routing gap.

Return the usable artifact, what was actually completed, what remains uncertain, and the next unfinished step. A question asking where work stands needs an answer; it does not automatically authorize executing the next step. If the user asks to continue, perform the already-authorized work and leave a dated resume point with links to the result.

Check whether externally reported artifacts are accessible here. Do not say a file is available merely because a different agent provided a path on another machine. Do not treat stale exports as current account state or assistant proposals as assigned tasks.

If records conflict, show the conflict and the smallest source check that would resolve it. If nothing is saved, say what is missing rather than inventing continuity.

After requested work, update the canonical resume point with the observed result, evidence date, and next unfinished action. Keep the work index as a route rather than a second status record. Completion follows the project criteria, not merely a file appearing.
