# From evidence to useful work

The OS follows one loop: **Source → Knowledge → Work → Feedback**. Each transition has an observable result.

| Stage | Question | Result |
|---|---|---|
| Source | What did we actually receive, and from whom? | An intact original, identity, provenance, and coverage limits |
| Knowledge | What can we reuse, and what supports it? | Findable synthesis with source links and explicit uncertainty |
| Work | What outcome can this help produce now? | A usable deliverable with an owner and next unfinished step |
| Feedback | What correction or result should change future behavior? | An accepted lesson, scoped to the relevant workflow and validated later |

For a personal learning project, selected notes supply evidence, useful concepts become knowledge, a practice plan turns them into work, and reflection improves the next session.

For a fictional sales call, the original notes are the source. Buyer objections and constraints become sourced knowledge. A proposed follow-up plan is work. A user's correction about the account is feedback. The proposal never becomes a customer commitment just because it was saved.

Three product rules shape every workflow:

1. For initial setup, begin with a short guided personalization of life and work, then offer a useful task. Ask for more context only when it changes the help.
2. Attach memory to evidence and a retrieval route. Storage without a way to use it is unfinished work.
3. Improve from observed friction. A new tool or agent is justified by a recurring need and an acceptance check.

Health is reported as concrete states: working, needs attention, or unverified, with evidence and scope. There is no composite maturity score. Value is assessed through time to useful output, time to resume, revision burden, and repeated use.

Weekly review prepares findings from actual work before asking questions. It may conclude that nothing needs changing. It can recommend simplifying a task, changing a workflow, or using a person. Building something new is not mandatory.
